📘 Facebook Clone Website

This is a Facebook website clone that I created during our Git tutorial.
The main purpose of this project was to practice Git, GitHub, HTML, CSS, and basic web development concepts.

🚀 About the Project

The Facebook Clone Website is a frontend project inspired by the design and layout of Facebook. It was created as a learning project to understand how websites are structured and how Git can be used to manage a project.

While working on this project, I learned how to create files, make changes, track those changes using Git, and upload the project to GitHub.

✨ Features
🏠 Facebook-inspired homepage
👤 User profile section
📰 News feed layout
💬 Comment section
👍 Like button interface
🔔 Navigation and notification sections
🎨 Facebook-inspired UI design
📱 Responsive layout
🖼️ Images and icons
📂 Organized project structure
🛠️ Technologies Used

💻 How to Run the Project
1. Clone the Repository

2. Open the Project
cd fb-clone-website

3. Run the Website

Open the index.html file in your web browser.

You can also use VS Code Live Server to run the project locally.
